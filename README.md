## About NEMISA CodeLab

**NEMISA CodeLab** is a personal learning and coding repository created to document practical work completed during the **NEMISA Bootcamp MicroCourse 1: Python Coding for Everyone!**

The repository is intended to serve as a growing portfolio of Python practicals, exercises, assignments, experiments, and mini-projects. It will also be used to demonstrate continuous learning and practical problem-solving as I prepare for future technology projects and hackathons.
